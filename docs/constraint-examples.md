# Exemples de contraintes enseignantes

## Dures possibles

- demi-journée libre : lundi matin ou vendredi après-midi ;
- aucune modification pour un enseignant ;
- indisponibilité ponctuelle ;
- maximum d'heures consécutives ;
- salle équipée obligatoire ;
- pause déjeuner ou temps de déplacement ;
- deux enseignants obligatoires sur un cours.

## Préférences possibles

- éviter la première ou dernière heure ;
- regrouper les cours ;
- réduire les trous ;
- déplacer d'abord entre collègues de la même équipe ;
- préférer certaines salles ou certains jours.

Chaque demande doit préciser : personne/groupe, semaine, jour, créneau, dure ou souple, et priorité si elle est souple.
