# Demande utilisateur — physique-chimie

## Objectif

Créer, pour chaque groupe possible, un bloc de deux créneaux consécutifs de physique-chimie.

## Priorités

1. respecter toutes les contraintes dures ;
2. conserver les heures totales de toutes les matières ;
3. déplacer le moins de cours possible ;
4. rester proche des créneaux actuels ;
5. réduire les trous.

## Sortie attendue

Liste des lignes Excel déplacées, ancienne et nouvelle position, ressources concernées, score et vérifications. Plusieurs variantes pourront être proposées.
